# Audio local de HERMES

`ruta-urbana.mp3` y `viaje-tranquilo.mp3` son piezas instrumentales sintéticas originales de 24 segundos, creadas para demostrar el reproductor de HERMES. No son grabaciones de una empresa, voces humanas ni canciones comerciales. No se emplearon archivos externos con derechos de autor.

Se generaron tonos senoidales y armónicos con una envolvente de decaimiento y se codificaron como MP3 mono a 64 kbps. El código de la página permite reproducir, pausar, detener, seleccionar pista, cambiar volumen y mover el progreso.
